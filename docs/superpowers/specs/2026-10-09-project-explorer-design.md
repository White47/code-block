## 产品与交互

沿用 React、现有深色青绿色主题和 Activity Bar。Explorer 侧栏中项目树为主要内容，保留项目选择／重新分析以及可折叠的视图与最近项目入口。文件夹按需展开，目录优先、名称排序；根及工具栏支持新建文件、新建文件夹、刷新、全部折叠。侧栏沿用现有收起能力。

单击文本文件使用现有源码标签，右键可侧边打开；文件夹单击展开／收起。右键菜单提供新建、重命名、删除；F2 改名、Delete 请求删除，不能抢占 Monaco 文本编辑按键。重名、权限、冲突、只读、加载失败均有明确反馈，目录显示加载中／空目录／继续加载。小屏仍保持可滚动的侧栏，不改变图画布主布局。

树来自磁盘而非 Symbol Index，未分析也可浏览。分析忽略规则不隐藏 Explorer 条目。`.git`、`.venv`、`venv`、`node_modules` 显示但默认折叠、只读；任何包含这些保护对象的祖先也不能改名或删除。项目根不可改名或删除。链接只显示标识，不遍历、不打开、不修改。

## 文本与草稿

保留现有 Python 编码 cookie、BOM、一致 EOL、版本冲突及原子保存合同。常见源码／配置／文档文本另有明确文件类型策略：严格 UTF-8／UTF-8 BOM 或 UTF-16 BOM，必须逐字节往返，拒绝二进制／NUL／不支持的编码；未知或超 5 MB 文件不当作文本打开。混合换行及 CR-only 保持只读。新建空文件不覆盖已有目标，新建目录不自动补建祖先。

不同标签和 split 共享项目／文件草稿。重命名／删除目录前，对后代已打开文档也执行保存／放弃／取消保护，并等待 pending save；取消或失败保留视图与草稿。完成保存后重新准备操作，不能沿用保存前版本。成功改名重建对应路径身份并重新打开已打开文件；成功删除关闭对应文件及 split，释放 model；旧路径保存版本失效，迟到回调不能复活旧身份。

任何文件创建／重命名／删除／移动成功后，已有分析标 Outdated，无分析保持 NotAnalyzed。保留旧图、布局及注释，不自动运行／导入代码或 Analyze，不伪造更新旧 SourceAnchor，不自动修 import。

## 后端边界

独立项目文件服务提供一层有界列表、独占创建和两阶段变更，与源码保存复用 bridge 串行化和当前项目生命周期。所有变更绑定 projectPath、当前打开 epoch、后端签发 revision；A→B→A 旧请求拒绝。

architect 已批准实施契约：`_open_project` 生成同一个 epoch 注入 Explorer 和文档服务；变更仅失效受影响路径，不轮换整个项目 epoch。只有根目录只读 bootstrap 允许省略 epoch，展开／分页必须校验；游标绑定目录版本。prepare token 60 秒、单次消费；guard 保存发生在文件变更入队前，避免嵌套队列死锁。Windows 回收同时设置 `FOFX_RECYCLEONDELETE | FOF_NOERRORUI | FOFX_EARLYFAILURE`，检查取消／逐项结果，不用旧接口回退。

列表每页 200 项；扫描和排序有界，超限明确反馈而不伪称完整。重命名／删除准备检查整个子树，最多 5,000 条目、深度 64、总内容指纹工作量 64 MB；超限拒绝变更。操作 token 单次、有期限，apply 再次核验条目内容／身份／父链／子树／保护项，不只看目录 mtime。

路径拒绝绝对路径、UNC、穿越、NUL、ADS、Windows 保留名、尾随点／空格；拒绝 reparse traversal、多硬链接及覆盖目标。大小写改名若无法安全实现，应明确拒绝而不是部分成功。剩余非协作外部 TOCTOU 竞态如实记录，不宣称绝对 CAS。

Windows 删除仅调用具备强制回收语义的本地系统接口；不支持／权限不足／用户取消／结果不确定时报错刷新，不回退 unlink/rmtree 或永久删除。恢复在系统回收站进行，不承诺应用内删除 Undo。[IFileOperation 标志说明](https://learn.microsoft.com/zh-cn/windows/win32/api/shobjidl_core/nf-shobjidl_core-ifileoperation-setoperationflags)。
