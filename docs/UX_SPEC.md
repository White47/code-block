# UX 规范

## 只读助手增量（2026-10-20，原生交付待验收）

右侧加入“检查器 / AI 助手”与关闭按钮，源码页也可提问；右上角、节点检查器、已保存函数/文件提供明确入口。打开、重开、配置、授权或选择节点不自动发送，每个问题主动提交；复用草稿退出/切换保护。

最终回答为七段纯文本和本地证据卡片，显示静态置信度、缺口、检查时间、预算预留/观测用量；临时流文本没有可信引用，过期卡片禁用。停止/关闭为尽力取消，区分回执与资源释放，不自动重试可能已计费的请求。available 不等于 SDK/API 可用，生产门禁仍关闭，详见 [助手指南](CODE_AGENT_GUIDE.md)。

## 源码编辑增量（2026-10-08，已实现）

现有 React PC 源码标签与侧边源码将使用离线 Monaco，支持 Python 彩色语法、行号、查找替换、撤销与折叠。不同锚点指向同一文件时共享草稿；普通标签切换不能丢失编辑或撤销历史。未保存标签显示 `●`，保存按钮与 Ctrl+S 显式提交。

关闭最后一个文件视图、替换侧边源码、切换项目、重新分析、重建工作区的设置操作与原生窗口退出，统一提供保存／放弃／取消。保存冲突或失败不得继续破坏性操作，不能强制覆盖外部修改。保存后旧分析标为 Outdated，不自动分析；未保存或过期时提示图中源码行定位可能失效。完整接口及权限合同见 [源码编辑](SOURCE_EDITING.md)，实际 PC 证据见 [编辑验收](SOURCE_EDITING_VALIDATION.md)。

## React 桌面实施口径（2026-10-03）

主入口为 React Flow / WebView2 原生 Windows 窗口；下文涉及 Tk 滚动条、快捷键缩放范围和固定 Overview 的描述仅作为 `codeviz-tk` 基线，不适用于新入口。React 中所有标签均可关闭，关闭最后一个标签回到概览；不会退出应用或清除分析结果。画布使用 React Flow 的拖移、缩放与 Fit，用户位置优先，自动布局纵向展开；大图不保证一屏容纳。

React 支持主图与最多三个同画布细节岛、节点选择 / Inspector、源码标签 / 侧边源码、搜索定位、上游 / 下游 / 双向和最多五跳查询。项目切换前保存待处理布局；设置保存与项目操作串行执行，过期异步响应不得覆盖新项目。Ignore Paths 为项目级，语言为应用级，均保存在应用数据目录。

Inspector 已提供锚点、判断依据、关系和数据；关系 / 成员目前仍可显示内部 ID，尚未达到下文易读名称及 12 条截断的目标。源码片段由独立源码标签或侧边完整文件提供，Inspector 内预览与完整键盘导航仍待补齐。以上是明确的当前实现差距，不视为完整 UX 目标已达成。

## 1. 布局

采用 VSCode 风格：左侧 Activity Bar / Sidebar，中间 Editor Area，右侧统一 Inspector。Activity 包含 Explorer、Search、Architecture、Execution、Symbols、Settings。

Editor 以 Tab 展示 Overview、Architecture、Training Flow、Source files；支持 Open to Side / Split，同时查看 Graph 与 Source。

应用保留操作系统原生标题栏和窗口关闭按钮。Overview 是固定首页；图、源码和 Problems 标签在右侧显示 `×`，也可以用 `Ctrl+W` 关闭当前标签。关闭标签不退出应用，不清除分析结果，重新打开时可继续阅读。

## 2. Overview

普通 Python 项目另有模块、类、函数 / 方法目录；选择具名函数可打开“函数流程”标签，无模型或训练入口也可以阅读。通用入口候选展示 confidence 和依据，不把函数名当作运行入口证明。FunctionFlow 节点同样支持 Inspector、源码标签 / 侧边源码、可关闭标签和缓存恢复；流程只覆盖所选作用域，不自动展开整个调用树。

通过选择本地项目文件夹打开项目，并提供 Recent Projects。首屏显示项目名、Language、Framework、Entry Points、Models、Main Areas、Analysis Health，以及 Analyze Project、Open Architecture、Open Training Flow、Browse Symbols。多个模型和入口并列列出；选择入口时进入对应的独立 Execution Flow。

## 3. 交互

- Architecture / Execution 采用 A+B 交互：A 是稳定的主纵向流程；单击只执行 Select、Inspector 和邻居高亮，不改变主图。对普通且可展开的节点，双击、Enter 或节点上的 `+` 在画布空白处打开 B 细节岛，不替换主图，也不改变主图根节点或展开历史。聚合节点执行同样动作时打开隐藏成员侧栏供选择 / 重新定位，不生成细节岛；不可展开节点不响应这些展开动作，用户可继续通过 Inspector 的 Open Source 查看源码。
- Symbol / Data Flow 是以所选符号或关键数据为中心的有界局部上下文；单击主图中可聚焦的普通节点时，可以重新查询并重新居中该节点的 1–5 hop 局部图，而不保证当前主图几何保持不变。
- 每个视图最多同时打开三个细节岛；岛可拖动、关闭，并以虚线连回来源节点。达到上限时提示先关闭一个，不自动淘汰已有岛。岛内节点可更新统一 Inspector 并打开对应源码，但不能继续嵌套新岛。
- Open Source / Open to Side：独立动作，不与打开细节岛混淆。细节岛标题中的 Open Source 默认打开来源节点；先选择岛内节点后，该动作打开所选岛内节点的源码。
- 关闭当前选中的细节岛后，选择返回主图来源节点；Escape 关闭当前活动岛，主图选择不受影响。
- Canvas 可通过方向键按确定顺序聚焦主图和细节节点；Enter 展开可展开的主节点，O 打开当前聚焦节点源码。键盘焦点使用虚线外框，不只依赖颜色。
- 返回、面包屑和当前视图状态必须可用；细节查询失败或失效只移除 / 跳过对应岛并显示提示，不能清空主图。
- 关闭标签：点击标签右侧 `×` 或按 `Ctrl+W`；Overview 不可关闭。
- 画布导航：`Ctrl+滚轮` 以指针为锚在 25%–250% 间缩放；普通滚轮和 Page Up / Page Down 纵向滚动，水平 / 垂直滚动条保持全部已绘制内容可达。左键拖动画布空白处或中键拖动执行可持久化的 canvas pan；拖动主节点或细节岛只移动对应对象。原生滚动条、普通滚轮和 Page Up / Page Down 产生的 Tk 滚动偏移仅用于当前会话，不写入 View State。
- 工具栏 Fit 将当前主图与细节岛适配到窗口，100% 恢复 1:1 缩放并尽量保留当前中心；缩放百分比实时显示。重置项目布局清除手动主节点位置，并把已打开岛恢复到自动放置，但不清除分析、展开状态、标签或各视图 viewport。

## 4. Inspector

统一分区：Overview（易读名、真实名、类型、语义角色、confidence、说明）；Structure / Flow；Relations；Data；Source（file/class/function/line range、片段、Open Source）。

节点默认只显示易读名称和真实代码名；路径、行号和局部关系放 Inspector。对大组件，Inspector 默认最多列出 12 条带易读名称的可见关系与 12 行源码预览，并提示未展开数量；Open Source 仍可查看完整文件，局部图负责继续探索关系，不在侧栏堆叠内部 ID。

## 5. 视图语义

Architecture 主关系为组件 + 数据流，Execution 主关系为控制流 + 数据流，Calls 主关系为 CALLS，Gradient 主关系为 GRADIENT_FLOW。Data Flow、Calls、Control、Loop、Gradient 使用不同视觉语义，并有 Legend；通用关系过滤器仍属后续能力。

Calls 入口打开有界的项目静态调用概览，不带入其他视图的选择或上次焦点。主图保留调用方、调用位置与原目标；包含线证明源码归属，CALLS 线保留原调用位置、目标、置信度与锚点，不代表运行时执行。单击只选中并更新 Inspector；“聚焦所选调用”才切换查询中心，提供上下游与 1–5 跳，“调用概览”返回全项目概览。聚合与失效选择不能聚焦。无静态调用时显示明确空状态，请求失败仍显示错误；源码与细节岛沿真实节点追溯，梯度独立视图仍未实现。

自动布局统一以从上到下为主，同级分支并列。Architecture 按 Contains；Execution / FunctionFlow 按容器与前向 Control Flow / Branch True / False，Loop Back 不推高层；Data Flow 按已投影的信息来源→使用方向；Symbol 按展示的包含 / 调用 / 导入 / 继承等依赖方向。Symbol / Data Flow 的查询焦点不强制位于最上方，允许上游在其上方。环压缩后稳定分层、环内并列，不代表并发或真实执行时序；断开的同级节点仍可并列。所有视图不使用随机坐标，手动位置保持原样、优先于自动布局。

2026-10-07 确认的修复合同：ProjectStructure / Architecture 的“更多层 / 更少层”控制结构深度 1–5，沿真实所有权或可追溯的自定义组件定义引用展示内部。Symbol / DataFlow 单独显示关系范围及上游 / 下游；FunctionFlow 不显示未参与查询的层数控件。更新中有状态，完成后显示实际新增 / 收起数量；无变化必须说明已到底、缺少内部信息或预算限制。模型组件、普通项目结构、函数流程不能统称为一个无解释的“框架”。具体实施和验收见 [结构展开修复](STRUCTURE_EXPLORATION.md)。

打开源码、设置或概览标签后返回同一图，不重置结构深度。React PC 界面按稳定的项目路径／视图／根记住本次应用会话中的显式层数；同一 context 的重渲染、重新分析或重开不能用迟到的初始提示覆盖它。首次进入未消费提示的 Architecture 模型根时，直属且已确认的 ModuleDict／ModuleList 容器可建议深度 2，其余默认 1；实际层数必须与工具栏一致。新项目或新根独立初始化，该会话深度不写入 Analysis Cache。投影卡片只增加“按定义展开”短标记，完整定义来源与实例上下文放 Inspector / 提示；节点和同级布局保持可读，不把未选中的深层结构淡化到难以辨认。

Architecture 细节岛以所选 occurrence 为相对根，最多展开相对 3 层，仍受全局 5 层和 18 节点／40 边预算约束；根详情应展示主图初始层级未展示的真实内部结构，不得简单复刻主图。局部选择只用于当前 Inspector，不替换持久化的主图选择。切换模型根时，其他根的合法岛和手动位置仅隐藏而非删除；内部查询异常不能被当作过期身份清理。

React 画布按实际测量卡片尺寸纵向分层，自动位置避让已保存的主卡及详情岛。尚未收到保存确认的手动拖动位置也必须保留。正交连线避让第三方卡片，平行关系分配不同主体通道；不删除真实关系来换取整洁。无法避障或达到路由预算时仍显示连线及警告，复杂图与用户手动重叠不承诺绝对零交叉。

换项目 / view / root 后，待节点测量和非零容器就绪自动定位新图。相同 context 恢复正常用户 viewport，不强制重排；若恢复位置令所有节点屏外，则自动适应。新细节岛及新展开结构按实际测量边界自动显现，不依赖额外适应点击；选择不反复移动相机。空图和迟到的旧 context 不重复调整。此前相机 / 容器修复的历史证据见 [画布恢复](CANVAS_RECOVERY.md)，不能代替本轮真实结构增减验收。

每个图视图分别保存 zoom / canvas pan，细节岛按视图保存来源节点与场景位置；重新打开项目时恢复有效状态。重新分析或加载旧结果时，引用已消失节点的岛会被安全清理。Outdated 状态允许继续浏览旧图，并在 Overview、图和源码区域保留警告。

## 6. 语言

默认为简体中文，Settings 中可在简体中文和 English 之间即时切换。语言是应用级偏好，保存在应用数据目录的独立、有大小限制的配置文件中，不写入被分析项目。切换只改变应用导航、按钮、状态、图例和检查器标题；真实源码、符号名、路径、行号和问题代码保持原样。

## 7. 搜索

项目文件浏览独立于 Analyze：Explorer 使用真实目录的分页懒加载树。目录可展开/折叠，文本可点击打开或侧边打开；工具栏与右键菜单提供新建、重命名、回收站删除与刷新。树内可拖到目标目录，或用“移动到…”输入相对目标目录（根留空）；允许／拒绝反馈使用常驻固定高度提示槽，不能推动目标行。读取能力和写入能力分别判断，安全只读文本仍可查看。目录操作涉及未保存文档时使用保存/放弃/取消保护；失败保留草稿和菜单目标输入，成功后只更新受影响标签，不清除无关草稿。具体交互及实现边界见 [项目资源管理器](PROJECT_EXPLORER.md)。

支持变量、参数、函数、方法、类、文件、模块、属性和语义匹配（如“反向传播”）。结果提供 Reveal in Graph、Open Source；默认展示 1-hop + 必要语义节点，并支持上游、下游和更多 hops。

## 8. 项目级 AI 理解与条目追问

先显式执行本地 Analyze，形成不依赖 AI 的静态项目概览、结构和模型架构。用户配置并授权后，主动点击“AI 分析项目”；成功结果自动反映到原 Project Overview / ProjectStructure / Architecture，三处共用一个项目理解版本，不自动打开第二个 AI 架构弹窗。保留“静态分析 / AI 增强”切换及原始健康度、模型、文件和符号信息。

项目结构与架构始终展示各自本地静态图及真实连线、层级和展开控件。AI 增强只附加同主区可折叠说明，七段中的全部非空内容均可查看；不会再用相同摘要卡片替代两张底图。静态 Inspector 继续服务当前真实节点。RelationFact 保留为支持关系文本和证据；没有可信端点映射时不往底图添加 AI 关系。小窗口主区支持上下滚动，折叠说明可扩大画布；键盘折叠标题不会触发底图详情。

解释不完整的标记保持原值，同时说明代表性采样、取证/预算缺口、未验证内容或尚未确定的具体原因。显示本地索引、授权、已提供索引和已提供源码片段四项计数，原自由文本缺口可展开查看；不能将静态图可用等同于 AI 已完整阅读项目。

2026-10-29 覆盖状态修订：原始 incomplete/coverageGaps/gapCodes 继续原样保存，但不再把 incomplete 一律渲染为同一句警告。只有服务端唯一、逐字匹配的代表性片段说明，且无其他原因/未知元数据时，显示普通提示“说明已生成，基于源码片段”。repair、预算/取证缺口、未验证或未知原因仍显示警告，原文可展开；未来或近似字符串默认保守警告。项目主区、聊天和旧架构视图共用同一展示逻辑。证据卡片 truncated 仅显示“源码片段已截取”，不冒充回答失败。

“向整个项目提问”或“围绕此节点提问”仅选择当前项目版本/条目并准备问题，仍需用户点击发送。上下文使用闭合条目引用，由服务查找原解释与依赖，不能把前端粘贴的旧答案当作可信上下文。当前聊天可以不同于项目理解的原会话；普通追问不更新项目版本，只有显式项目分析更新它。条目过期后阻止沿旧条目发送，但仍允许明确更新项目分析。

项目分析由项目拥有：关闭侧栏、切聊天不取消，主区跨视图保留进度与停止。普通聊天和该面板明确发起的导航仍随面板关闭取消；恢复的导航观察者只监控资源，不冒充面板消费者。主区导航按项目版本与原标签页/视图/根消费，切页、关页、清空原会话或替换版本后不得抢焦点；打开源码仍经过已保存内容/草稿保护及原C6校验。

界面分别显示本地索引、授权、实际提供元数据、实际提供源码片段的文件数；片段不代表完整文件已读或项目已完全理解。预留字符栏同时包含源码与衍生解释，重复发送重复计量，预留量不等于账单。语言切换只翻译界面，不改源码与模型原文。
